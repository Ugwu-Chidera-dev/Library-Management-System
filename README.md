# Library Management System
### Description
This is an object Oriented Library System CLI that stores the librarian, members, books and borrow records as objects that can be accessed independent of the internal state of the class.

### Functionality
It creates books with unique ISBN, members with unique IDs and Librarians with unique IDs too. It generates borrow records of the borrowed books with timestamps of the borrowing date and the return date. All this is stored in the Library and can be accessed by the librarians on duty.

### Technologies
It is primarily built on Python PL and currently working on adding a database to it where records can be stored and retrieved.
No requirements document is needed yet.

### Procedures
To be able to run this successfully, first clone the repository with;\
`git remote add origin https://github.com/Ugwu-Chidera-dev/Library-Management-System`
 and then you can run and test it.
